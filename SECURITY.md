# Security and safety

This utility can permanently delete files and Windows Registry data. Its safe
default is preview-only mode (`"dry_run": true`). Never publish a release with
preview mode disabled in `config.json`.

Please report security issues privately through GitHub Security Advisories.
Do not include private registry exports, usernames, access tokens, or complete
logs in public reports.

The project is independent and is not affiliated with Valve Corporation or
Steam.
